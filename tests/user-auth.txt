# User Authentication Test Cases
# CrimeLens - Citizen Auth Implementation

## Test Environment Setup
- Backend: http://localhost:5001
- Frontend: http://localhost:5173
- Browser: Chrome/Edge (DevTools open)
- Supabase: Configured and accessible

## 1. REGISTRATION TESTS

### Test 1.1: Valid Email Registration
**Steps:**
1. Navigate to `/register-citizen`
2. Enter valid email: `test@example.com`
3. Enter password: `password123` (6+ chars)
4. Enter full name: `Test User`
5. Submit form

**Expected Results:**
- ✅ Registration successful
- ✅ Redirected to `/complete-profile`
- ✅ Token stored in localStorage (`citizen_token`)
- ✅ User data stored in localStorage (`citizen`)
- ✅ `isProfileComplete: false` in user data

**Bug Check:**
- [ ] Error if email already registered (should show "Email already registered")
- [ ] Error if password < 6 characters
- [ ] Error if invalid email format

---

### Test 1.2: Duplicate Email Registration
**Steps:**

### Test 1.3: Invalid Email Format

## 9. SECURITY TESTS

### Test 9.1: Cannot Access Protected Routes Without Auth
**Steps:**
1. Clear localStorage
2. Try to access: `/citizen-dashboard`, `/complete-profile`, `/api/citizens/my-reports`

**Expected Results:**
- ✅ All redirect to `/login-citizen`
- ✅ API endpoints return 401

---

### Test 9.2: Token Validation
**Steps:**
1. Login and copy token from localStorage
2. Use token in Postman/curl: `GET /api/citizens/my-reports` with `Authorization: Bearer <token>`

**Expected Results:**
- ✅ Request succeeds with valid token
- ✅ Request fails with invalid/expired token

## 10. API RESPONSE FORMAT TESTS

### Test 10.1: Check Success Response Format
**Steps:**
1. Login and check console logs
2. Verify response structure

**Expected Format:**
```json
{
  "success": true,
  "user": { ... },
  "session": {
    "accessToken": "...",
    "refreshToken": "...",
    "expiresIn": 3600
  },
  "message": "Login successful"
}
```

---

### Test 10.2: Check Error Response Format
**Steps:**
1. Try to login with wrong password
2. Check console logs

**Expected Format:**
```json
{
  "success": false,
  "error": "Invalid credentials",
  "code": "UNAUTHORIZED"
}
```
